<h1 align="center"> Installation </h1>

1. Download the source code.
2. Extract the code to a directory.
3. Open chrome://extensions.
4. Enable developer mode (checkbox in right corner).
5. Refresh the page.
6. Drag the directory containing the source code to the page.
7. Done.

If you do not want to use the extension, you can also set your default homepage to `https://nimplex.github.io/Minimal-StartPage`.
